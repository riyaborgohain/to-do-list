# Simple To-Do List App

A lightweight, responsive To-Do List application built with pure HTML, CSS, and modern JavaScript.

## Features

- **Divided by Dates**: Tasks are organized into clean date sections (`Overdue`, `Today`, `Tomorrow`, `Upcoming Dates`, and `Without Date`).
- **Calendar Button & Date Filtering**: Quickly filter tasks using the 📅 Calendar button with presets (`Today`, `Tomorrow`, `Upcoming`, `Overdue`) or pick any specific calendar date.
- **Burger Menu**: Accessible slide-in navigation drawer in the top right corner with date views, task management actions (Clear Completed, Clear All), and project links.
- **Task Statuses**: Organize tasks by `Unfinished`, `Paused`, and `Completed`.
- **Counters**: View total task count as well as breakdown by status in real-time.
- **Search & Status Filters**: Search tasks by title or status, plus quick-filter tabs.
- **Edit & Quick-Change**: Modify task titles, due dates, or switch statuses on the fly.
- **Delete Confirmation**: Confirmation prompt before deleting any task.
- **Local Persistence**: Stored via `localStorage` in the browser — persists across refreshes.
- **Responsive Design**: Clean UI optimized for mobile phones, tablets, and desktops.
- **Zero Dependencies**: Runs directly in any modern web browser without a server or backend.

## Getting Started

Simply open `index.html` in your web browser.
